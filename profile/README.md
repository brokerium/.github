<p align="center">
  <b>The control plane for Apache Kafka® KRaft clusters</b><br>
  One place to see every cluster, scale brokers and controllers on the fly, rebalance data and
  upgrade Kafka safely, on virtual machines, Kubernetes and managed services.
</p>

- **Multi-cluster dashboard:** health, brokers, the KRaft quorum, topics, partition distribution
  and consumer groups in one view.
- **Controllers without downtime:** add and remove KRaft controllers, migrate static quorums to
  dynamic ones.
- **Rebalancing you control:** a preview before every move, one-click even balancing, throttled
  and behind health gates.
- **Broker lifecycle and rolling upgrades:** add, drain, replace and decommission brokers;
  upgrade one node at a time and finalize explicitly.
- **Everywhere Kafka runs:** a small agent on virtual machines, Strimzi on Kubernetes, Amazon
  MSK, Confluent Cloud and Aiven.
